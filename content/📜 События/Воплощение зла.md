# Воплощение зла
> *Масштабная кампания в [[Кормир|Кормире]]: коронация нового наследника, красные маги, повелители демонов и рост [[Орден Древних|Ордена Древних]].*

| | |
|---|---|
| **Дата** | 1512–1522 ЛД |
| **Место** | [[Кормир]], [[Марсембер]] |
| **Участники** | [[Красные маги Тэя]], повелители демонов, [[Акар Кессел]], [[Орден Древних]] |
| **Кампания** | Воплощение зла |
| **Исход** | [[Марсембер]] спасён; луна исчезла; [[Орден Древних]] вырос в силе |

## Описание
Кампания в [[Кормир|Кормире]], связанная с коронацией нового наследника. В события вовлечены [[Красные маги Тэя]], повелители демонов и [[Акар Кессел]]. [[Марсембер]] был спасён. Луна исчезла. [[Орден Древних]] значительно вырос в силе.

## Последствия
- [[Марсембер]] спасён
- Луна исчезла
- [[Орден Древних]] значительно усилился
- [[Пепельный дозор]] уничтожен [[Акар Кессел|Акаром Кесселом]]
