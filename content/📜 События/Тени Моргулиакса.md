# Тени Моргулиакса
> *Кампания по низвержению [[Ллос]] и завоеванию [[Подземье|Подземья]] [[Моргулиакс|Моргулиаксом]].*

## Основные сведения
| | |
|---|---|
| **Дата** | 1504–1508 ЛД |
| **Место** | [[Подземье]], [[Врата Балдура]] |
| **Участники** | [[Моргулиакс]], [[Медив]], [[Гислен]], [[Фенрис]], [[Делайла]], [[Рэндал Ортеган|Рэндал]], [[Урхний Талоф]], [[Велура]] |
| **Кампания** | Тени Моргулиакса |
| **Исход** | [[Ллос]] низвергнута; [[Велура]] вознеслась |

## Описание
Кампания, связанная с низвержением [[Ллос]]. [[Моргулиакс]] завоевал [[Подземье]]. Игровые персонажи: [[Медив]], [[Гислен]], [[Фенрис]], [[Делайла]]. Союзники: [[Рэндал Ортеган|Рэндал]], [[Урхний Талоф]]. Кульминацией стала битва у [[Врата Балдура|Врат Балдура]]. [[Велура]] вознеслась.

## Последствия
- [[Ллос]] низвергнута
- [[Моргулиакс]] завоевал [[Подземье]]
- [[Велура]] вознеслась

## Связанные события
- [[Ритуал Планарного единства]] — [[Моргулиакс]] получил знания после провала ритуала
