# Битва в Мифриловой кузне
> *Сражение [[Вершители|Вершителей]] в [[Мифриловый Зал|Мифриловой кузне]], гибель [[Цефея|Цефеи]] и самопожертвование [[Мирдалил|Мирдалила]].*

## Основные сведения
| | |
|---|---|
| **Дата** | ~1481 ЛД |
| **Место** | [[Мифриловый Зал]], Мифриловая кузня |
| **Участники** | [[Вершители]], [[Цефея]], [[Гангренот]], [[Азавкиель]], [[Мирдалил]] |
| **Кампания** | [[Эра Тьмы]] |
| **Исход** | [[Цефея]] убита; [[Мирдалил]] пожертвовал собой |

## Описание
[[Вершители]] убили [[Цефея|Цефею]]. [[Азавкиель]] забрал её душу. [[Гангренот]] применил [[Абсолют Мортум]] против [[Вершители|Вершителей]]. [[Мирдалил]] пожертвовал собой, чтобы спасти остальных.

## Последствия
- [[Цефея]] убита, её душа забрана [[Азавкиель|Азавкиелем]]
- [[Мирдалил]] погиб
- [[Гангренот]] применил [[Абсолют Мортум]]
