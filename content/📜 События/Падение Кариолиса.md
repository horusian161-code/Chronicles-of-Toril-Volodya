# Падение Кариолиса
> *Уничтожение [[Кариолис|Кариолиса]] [[Асерарак|Асерараком]], воскресившим трёх генералов.*

## Основные сведения
| | |
|---|---|
| **Дата** | ~1471 ЛД |
| **Место** | [[Кариолис]] |
| **Участники** | [[Асерарак]], [[Вершители]], [[Нурганлиш]], [[Секутор Мевикс]] |
| **Кампания** | [[Эра Тьмы]] |
| **Исход** | Город уничтожен; Вершители спасены |

## Описание
[[Асерарак]] воскресил трёх своих генералов и уничтожил [[Кариолис]]. [[Вершители]] были спасены из города благодаря [[Нурганлиш|Нурганлишу]] и [[Секутор Мевикс|Секутору Мевиксу]]. На руинах [[Кариолис|Кариолиса]] был возведён [[Зиккурат Злобы]].

После этого события группа героев получила своё имя — [[Вершители]].

## Последствия
- [[Кариолис]] полностью уничтожен
- [[Зиккурат Злобы]] возведён на руинах
- Группа героев получила имя «[[Вершители]]»

## Связанные события
- [[Эра Тьмы]] — основная кампания
- [[Ритуал Планарного единства]] — проведён на [[Зиккурат Злобы|Зиккурате Злобы]]
