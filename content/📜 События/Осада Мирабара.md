# Осада Мирабара
> *Атака [[Легион Асерарака|Легиона]] на [[Мирабар]], первое поражение [[Асерарак|Асерарака]].*

## Основные сведения
| | |
|---|---|
| **Дата** | ~1481 ЛД |
| **Место** | [[Мирабар]] |
| **Участники** | [[Легион Асерарака]] ([[Цефея]], [[Гангренот]]), [[Вершители]], [[Ширраксус]], [[Квинилиолиш]] |
| **Кампания** | [[Эра Тьмы]] |
| **Исход** | Первое поражение [[Асерарак|Асерарака]]; два некрополя уничтожены |

## Описание
Силы [[Легион Асерарака|Легиона]] под командованием [[Цефея|Цефеи]] и [[Гангренот|Гангренота]] атаковали [[Мирабар]], пока [[Вершители]] входили в [[Мифриловый Зал]].

Некрополь Алькор был уничтожен [[Ширраксус|Ширраксусом]] и [[Квинилиолиш]]. Некрополь Брахиум был уничтожен [[Вершители|Вершителями]]. Это стало первым поражением [[Асерарак|Асерарака]].

## Последствия
- Некрополь Алькор уничтожен
- Некрополь Брахиум уничтожен
- Первое поражение [[Асерарак|Асерарака]]
