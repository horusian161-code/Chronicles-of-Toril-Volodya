# Возрождение Тиамат
> *Кампания по призыву [[Тиамат]], предотвращённая героями при поддержке [[Зариэль]].*

## Основные сведения
| | |
|---|---|
| **Дата** | 1484–1489 ЛД |
| **Место** | [[Колодец Силы|Колодец]], [[Баатор]] |
| **Участники** | [[Культ Дракона]], [[Ролун Гринсвер|Ролун]], [[Сталебрад]], [[Лия]], [[Резмир]], [[Зариэль]] |
| **Кампания** | Возрождение Тиамат |
| **Исход** | [[Тиамат]] призвана у Колодца, побеждена, убита на [[Баатор|Бааторе]] при поддержке [[Зариэль]] |

## Описание
[[Культ Дракона]] активно действовал, стремясь к возрождению [[Тиамат]]. Героям — [[Ролун Гринсвер|Ролуну]], [[Сталебрад|Сталебраду]] и [[Лия|Лие]] — удалось противостоять культу. [[Резмир]] был захвачен в плен.

[[Тиамат]] была призвана у [[Колодец Силы|Колодца]], побеждена, а затем убита на [[Баатор|Бааторе]] при поддержке [[Зариэль]].

## Последствия
- [[Тиамат]] убита на [[Баатор|Бааторе]]
- [[Культ Дракона]] разгромлен
- [[Резмир]] захвачен, позже присоединился к [[Орден Древних|Ордену Древних]]
