# Омония
> *Меч [[Гангренот|Гангренота]], источник его жизни. Также известен как **Убийца всего неживого**. Один из компонентов [[Меч священного гнева|Меча священного гнева]].*

## Описание

Омония — меч [[Гангренот|Гангренота]], являющийся источником его жизни. Связан с Гангренотом через [[Оковы Предписания]]. Один из двух компонентов [[Меч священного гнева|Меча священного гнева]] (второй — [[Церония]]).

## История

1. Омония связана с [[Гангренот|Гангренотом]] через пакт [[Оковы Предписания]].
2. С 1464 года была запечатана в семейном хранилище [[Ренот]].
3. Освобождена, когда [[Асерарак]] воскресил [[Гангренот|Гангренота]].
4. Объединена с [[Церония|Церонией]] для создания [[Меч священного гнева|Меча священного гнева]].

## Примечания мастера

Источник жизненной силы Гангренота. Без Омонии его существование невозможно.
