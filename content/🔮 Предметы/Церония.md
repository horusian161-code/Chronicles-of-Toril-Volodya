# Церония
> *Бывший меч [[Гет Лакмен|Гета Лакмена]], также известный как **Вестница гибели**. Один из компонентов [[Меч священного гнева|Меча священного гнева]].*

## Описание

Церония — меч, ранее принадлежавший [[Гет Лакмен|Гету Лакмену]]. Один из двух компонентов [[Меч священного гнева|Меча священного гнева]] (второй — [[Омония]]).

## История

1. Церония принадлежала [[Гет Лакмен|Гету Лакмену]].
2. После превращения Гета Лакмена в нежить меч перешёл к его родственникам в [[Лускан|Лускане]].
3. [[Гангренот]] похитил Церонию во время нападения на [[Лускан]].
4. Объединена с [[Омония|Омонией]] для создания [[Меч священного гнева|Меча священного гнева]].

## Примечания мастера

Вместе с [[Омония|Омонией]] составляет [[Меч священного гнева]] — один из пяти артефактов [[Ритуал Планарного единства|Ритуала Планарного единства]].
