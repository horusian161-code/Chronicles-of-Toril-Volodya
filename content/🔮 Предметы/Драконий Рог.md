# Драконий Рог
> *Магический артефакт подчинения драконов. Использован [[Ландер Натроп|Ландером Натропом]] для порабощения [[Нурганлиш]].*

## Основные сведения

| | |
|---|---|
| **Тип** | Артефакт |
| **Владелец** | [[Ландер Натроп]] |
| **Местонахождение** | У [[Ландер Натроп|Ландера Натропа]] |
| **Статус** | Использован |

## Описание

Драконий Рог — магический артефакт, позволяющий подчинять драконов своей воле.

## История

[[Ландер Натроп]] использовал Драконий Рог, чтобы заставить [[Нурганлиш]] служить ему.
