# Хроностиаз
> *Легендарный меч, найденный [[Рэндал Ортеган|Рэндалом Ортеганом]] после обретения звания [[Рыцарь Храма|Рыцаря Храма]]. Позволяет искривлять пространство и двигаться с невероятной скоростью.*

## Основные сведения

| | |
|---|---|
| **Тип** | Легендарное оружие (меч) |
| **Владелец** | [[Рэндал Ортеган]] |
| **Местонахождение** | У [[Рэндал Ортеган|Рэндала Ортегана]] |
| **Статус** | Активен |

## Описание

Хроностиаз — легендарный меч, обладающий способностью искривлять пространство. Даёт владельцу возможность двигаться с невероятной скоростью.

## История

Найден [[Рэндал Ортеган|Рэндалом Ортеганом]] после того, как тот стал [[Рыцарь Храма|Рыцарем Храма]].
