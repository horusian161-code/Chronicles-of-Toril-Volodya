# Рубрикатор
> *Древняя машина для переписывания реальности, один из пяти артефактов [[Ритуал Планарного единства|Ритуала Планарного единства]]. Создан божеством [[Вектор|Вектором]].*

## Основные сведения

| | |
|---|---|
| **Тип** | Артефакт (машина) |
| **Владелец** | Первоначально — [[Вершители]], затем — [[Гангренот]] |
| **Местонахождение** | Украден [[Гангренот|Гангренотом]] у [[Вершители|Вершителей]] |
| **Статус** | Украден |

## Описание

Рубрикатор — древняя машина, способная переписывать реальность. Создана божеством [[Вектор|Вектором]].

## История

1. Рубрикатор был создан [[Вектор|Вектором]].
2. [[Ширраксус]] передал Рубрикатор [[Вершители|Вершителям]].
3. [[Гангренот]] похитил артефакт у [[Вершители|Вершителей]].
4. Гангренот намеревался переписать реальность на [[Трон Времени|Троне Времени]] посредством механизма [[Хрон-Энд-Вайл-Рубри]].

## Примечания мастера

Один из пяти артефактов [[Ритуал Планарного единства|Ритуала Планарного единства]] наряду со [[Сфера Аннигиляции|Сферой Аннигиляции]], [[Око Пророка|Оком Пророка]], [[Меч священного гнева|Мечом священного гнева]] и [[Мифриловая кузня|Мифриловой кузней]].
