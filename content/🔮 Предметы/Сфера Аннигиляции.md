# Сфера Аннигиляции
> *Один из пяти артефактов, необходимых для [[Ритуал Планарного единства|Ритуала Планарного единства]].*

## Основные сведения

| | |
|---|---|
| **Тип** | Артефакт |
| **Владелец** | [[Асерарак]] |
| **Местонахождение** | У [[Асерарак|Асерарака]] |
| **Статус** | Принадлежал Асерараку с начала событий до конца [[Эра Тьмы|Эры Тьмы]] |

## Описание

Сфера Аннигиляции — один из пяти ключевых артефактов, необходимых для проведения [[Ритуал Планарного единства|Ритуала Планарного единства]].

> [!question] Требует уточнения у мастера
> Точные свойства и внешний вид Сферы Аннигиляции.

## История

Сфера находилась во владении [[Асерарак|Асерарака]] ещё до начала основных событий кампании и оставалась у него вплоть до завершения [[Эра Тьмы|Эры Тьмы]].

## Примечания мастера

Один из пяти артефактов [[Ритуал Планарного единства|Ритуала Планарного единства]] наряду с [[Око Пророка|Оком Пророка]], [[Меч священного гнева|Мечом священного гнева]], [[Рубрикатор|Рубрикатором]] и [[Мифриловая кузня|Мифриловой кузней]].
