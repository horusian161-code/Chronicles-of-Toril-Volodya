# Око Пророка
> *Один из пяти артефактов для [[Ритуал Планарного единства|Ритуала Планарного единства]], найденный [[Асерарак|Асерараком]] в [[Кариолис|Кариолисе]].*

## Основные сведения

| | |
|---|---|
| **Тип** | Артефакт |
| **Владелец** | [[Асерарак]] |
| **Местонахождение** | [[Кариолис]] (место обнаружения) |
| **Статус** | Найден Асерараком |

## Описание

Око Пророка — один из пяти ключевых артефактов, необходимых для проведения [[Ритуал Планарного единства|Ритуала Планарного единства]].

> [!question] Требует уточнения у мастера
> Точные свойства и внешний вид Ока Пророка.

## История

Око Пророка было обнаружено [[Асерарак|Асерараком]] в [[Кариолис|Кариолисе]] при содействии [[Агентство Уртаном|Агентства Уртаном]] и [[Лорд Атанатос|Лорда Атанатоса]]. Поиск и обретение этого артефакта являлись главной целью Асерарака в Кариолисе.

## Примечания мастера

Один из пяти артефактов [[Ритуал Планарного единства|Ритуала Планарного единства]] наряду со [[Сфера Аннигиляции|Сферой Аннигиляции]], [[Меч священного гнева|Мечом священного гнева]], [[Рубрикатор|Рубрикатором]] и [[Мифриловая кузня|Мифриловой кузней]].
