# Манускрипт Планарных ключей
> *Древняя карта для нахождения Планарных ключей — истинной цели [[Ритуал Планарного единства|Ритуала Планарного единства]].*

## Основные сведения

| | |
|---|---|
| **Тип** | Артефакт (карта/манускрипт) |
| **Владелец** | [[Моргулиакс]] (в итоге) |
| **Местонахождение** | Собран [[Моргулиакс|Моргулиаксом]] у [[Врата Балдура|Врат Балдура]] |
| **Статус** | Собран воедино |

## Описание

Манускрипт Планарных ключей — древняя карта, указывающая путь к Планарным ключам. Планарные ключи являлись истинной целью [[Ритуал Планарного единства|Ритуала Планарного единства]].

## История

1. [[Ритуал Планарного единства]] провалился.
2. В результате провала ритуала [[Моргулиакс]] получил знание о местонахождении Манускрипта.
3. Во время событий [[Тени Моргулиакса]] Манускрипт был расколот на части.
4. [[Моргулиакс]] собрал все части воедино у [[Врата Балдура|Врат Балдура]].

## Примечания мастера

Истинная цель ритуала — не сам ритуал, а получение информации о Планарных ключах через этот Манускрипт.
