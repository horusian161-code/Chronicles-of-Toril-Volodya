# Знак Избранного
> *Нейтральная фракция [[Сигил|Сигила]], ведущая партизанскую войну против [[Орден Древних|Ордена Древних]].*

## Основные сведения
| | |
|---|---|
| **Тип** | Нейтральная фракция |
| **Лидер(ы)** | Фактол [[Дариус]] |
| **Штаб** | Зал Ораторов, [[Сигил]] |
| **Статус** | Активна (партизанская война) |

## Описание
Знак Избранного — нейтральная фракция [[Сигил|Сигила]], базирующаяся в Зале Ораторов. Ведёт партизанскую войну против [[Орден Древних|Ордена Древних]].

## Члены
- Фактол [[Дариус]] — лидер

## История
После завоевания [[Сигил|Сигила]] [[Орден Древних|Орденом Древних]] фракция перешла к партизанской войне.

- [[Орден Древних]] — противник
