# Пепельный дозор
> *Организация, уничтоженная [[Акар Кессел|Акаром Кесселом]] в ходе кампании [[Воплощение зла]].*

## Основные сведения
| | |
|---|---|
| **Тип** | Военная организация |
| **Лидер(ы)** | [[Зеренна Пепельная заря]] |
| **Штаб** | Великий Лесной штаб (уничтожен) |
| **Статус** | Уничтожен |

## Описание
Пепельный дозор был уничтожен [[Акар Кессел|Акаром Кесселом]]. Великий Лесной штаб был разрушен.

## Члены
- [[Зеренна Пепельная заря]] — лидер

## История
Пепельный дозор действовал во время кампании [[Воплощение зла]]. Был уничтожен [[Акар Кессел|Акаром Кесселом]], Великий Лесной штаб разрушен.
